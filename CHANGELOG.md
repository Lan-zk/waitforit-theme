# Changelog

## v0.1.0 - 2026-10-22

- Six content entries: blog, essays, projects, fiction, photography, about. Blog, essays and projects have dedicated templates; other types use generic templates.
- Shared tags, paginated archives and bilingual fictional boundary fixtures.
- A single-screen Psalm 23:2 home, compact language switch and hidden footer mark.
- Full-height reading, progressive edge blur, compact inline tags and themed shepherd's crook cursors.
- Original WebGL2 meadow and downstream water, reduced-motion/static fallback and context recovery.
- Consumer configuration coverage and Chrome browser acceptance gates, failure artifacts and installation documentation.

Browser validation is limited to Chrome, and to a simulated narrow viewport; no other browser, physical mobile device or screen reader has been verified.
