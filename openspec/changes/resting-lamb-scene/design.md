## Context

动机与范围见 proposal；视觉输入为 docs/design/resting-lamb-scene-brief.md。当前原创海面逐帧计算全屏透视场，已有双 Canvas、纸光、静态颗粒、固定框架与暂停机制。构建管线保持本地资源指纹/SRI（AST-01/02/04/16），partial 保持新路径（TPL-03）。

## Goals / Non-Goals

地形、岸线和草根固定；草梢与水纹连续轻动；1440/390 昼夜可辨且正文稳定。保留无 JS/Canvas 失败/关闭路径。范围不含品牌改形、字体、导航、OG 或发布。

## Decisions

- 用 Canvas 2D 缓存静态纸墨地面与草簇，逐帧仅复合缓存、绘制有限活动草梢与水纹。相较继续全屏波面计算，空间材质明确且成本有界；不加库（AST-16）。
- 固定种子、归一化曲线共用昼夜几何，小屏单独调整溪流横向位置；草叶与天空内部宽度最多1440，水面单独采样到等效视口宽度最多900。双画布按主题着色，900ms 交叉淡化沿用。
- 按用户第三轮反馈，统一12s空间风场驱动草弯曲与水波偏移/强弱；中近景均参与、标称草摆7px，保留静止远景。水道前景20vw/0.45vh细波，18px浅水过渡与疏密贴岸草共用固定覆盖函数；保留原波场，不再独立计时。reduce共享周期归零并停止RAF（AST-16）。
- 唯一开关改为 features.scene，删除 sea 键与海浪令牌，不做旧键兼容（CFG-05/07/08）；scene/scripts partial 的条件同步（TPL-03）。
- 单一 RAF 限制 24 逻辑帧/秒，复用 100ms 步长上限与所有暂停/恢复事件。测试改按 day 目标画布一次静态缓存复合计为一逻辑帧，避免把路径/双画布当帧数。
- 修改 DESIGN 后重生成 sidecar 场景与叙事，资产门禁保持原有字体/颜色/装饰限制。新场景视觉指标为约六秒局部变化及阅读区稳定，不沿用两秒大面积海面变化率。

## Risks / Trade-offs

- 草纹密度可能导致低采样闪烁 → 控制长度/数量并复核昼夜录像，不提高全屏 DPR。
- 窄溪可能读作道路 → 用固定柔岸和水道内连续流纹区分，静帧先验收。
- 桌面模拟不能证明真实手机/跨引擎性能 → 同环境前后测至少 10 秒并明确交接边界。

## 本地实时调参工具

独立 HTML 由 Node 内置 HTTP 服务提供 `/tune/`，同源 iframe 加载指定 Hugo 构建目录。控制面板不进入 Hugo 资源发布管线；主题只消费 CSS 参数及每帧合并的 `wf:scene-update` 事件，保持默认 24fps 和静态降级（AST-16）。参数 JSON 使用带单位的 CSS 变量名，导入白名单及范围校验；本地存储仅在调参页使用。桌面/手机预览改变实际 iframe 布局尺寸，外部缩放仅适配工作台空间。验证参数往返、画布变化、视口、昼夜及普通页面无面板（REL-07）。

## 用户回传参数与交叉水纹

按回传JSON将16项CSS参数采纳为默认值，并同步调参页重置值；day/desktop不改变主题默认auto。水波沿用三方向解析波，频率从原海面3.6倍降至1.8倍、高度权重改为0.42/0.34/0.24、相位错开；斜光调整为同时显出三组坡度，修正原受光导致一组主导的平行条带。固定岸线和共用风场不变。相同回传参数下保存双尺寸昼夜前后对照；检查降级、性能和JSON重置/往返（AST-16、REL-07/08）。

## 实站材质对照后的修订

按D31保留16项用户参数，草叶改为固定根部的尖端曲面，移除旧三叉草簇；五个波纹尺度叠加，在随河道弯曲的透视坐标内缓慢下游流动，局部反射和共用风场形成波光。固定星点与远景缓存，夜间更明显；首页顶部纸光变薄，主句仍受保护。草叶/星点与水面分别使用不同采样尺寸以兼顾清晰度和CPU成本；24fps上限、暂停与静态降级不变（AST-16）。验收以本轮实际截图/录像、性能、调参和双版构建为准（REL-07/08）。
