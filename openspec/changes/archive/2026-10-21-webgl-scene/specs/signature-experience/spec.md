# Spec Delta

## MODIFIED Requirements

### Requirement: 安歇草地与窄溪

场景 MUST 以纸墨单色呈现低伏草地与一条前景约26.5vw宽的溪流，溪水以多尺度交叉波、透视坡面反射与局部高光呈现流动，避免单组平行条带主导；草叶 MUST 具有清楚的尖端与曲线，不以低分辨率草簇放大代替；天空 MUST 有确定性固定星点，夜间更明显，不闪烁、不漂移且不干扰阅读；地形、岸线与草根固定，中近景草簇和水面明暗 MUST 由同一空间风场缓慢连续驱动，相邻草簇有共同风向与传播节奏，根部固定；溪岸 MUST 以浅水渐变及疏密贴岸草簇自然衔接，避免整齐切线；1440/390两档昼夜 MUST 保持构图可辨，正常状态六至八秒内可察觉局部变化，中央主句和阅读区保持稳定。每秒绘制 MUST 不超过24个逻辑帧；后台、离页、减少动效或saveData MUST停止循环；减少动效/saveData MUST呈现确定性静态首帧。features.scene=false MUST不输出Canvas或场景脚本；无JS、WebGL2 不可用或场景初始化失败 MUST保持正文与导航可用。旧features.sea开关移除。

#### Scenario: 动画与恢复
- **WHEN** 正常页面经过时间后进入后台再恢复
- **THEN** 仅局部草梢与水纹变化，地形岸线不移动，后台无持续绘制，恢复平滑继续

#### Scenario: 静态降级
- **WHEN** reduce motion、saveData、关闭场景、无JS 或 WebGL2 不可用
- **THEN** 无持续动画，正文导航正常；reduce/saveData保留静态景观，关闭、无JS 或 WebGL2 不可用保留纸光颗粒底面

#### Scenario: 昼夜与小屏
- **WHEN** 在1440/390切换昼夜
- **THEN** 相同地形与草簇保持稳定，窄溪在两档可辨，切换900ms内完成且无闪白

#### Scenario: 渲染失败与恢复
- **WHEN** WebGL2 上下文创建失败、着色器初始化失败，或运行中上下文丢失
- **THEN** 页面不出现空白画布或持续动画，正文、导航、纸光与颗粒可用且无报错；上下文恢复后景观在原状态下继续，不阻断阅读
