# Design

- home只输出hero，删去Recent与.Content，首页主滚动区不产生第二屏（TPL-05/16）。
- footer标识块display:none，控件靠右；双语只渲染目标语言链接，地址取当前翻译或语言首页，多语details、单语不渲染（CNT-19/21，CFG-23/24）。
- 延续已有WebGL2资源管线与内联shader。五组方向波共享下游平流坐标，波峰以一次高度交点估计产生位移；波形一起推进并产生坡度法向，用视线与半程光向量计算宽反光/亮点；fwidth在coverage分支前计算，远处高频衰减，水体外片元跳过昂贵波计算。浅水幅度与流速降低，岸线mask不动；地形窄湿润带和外侧短草连接材质（AST-15/16）。
- 不改路径、参数数量、24fps、静态缓存、reduce/saveData/后台/丢上下文降级。用同环境前后静帧、六秒运动、连续帧纹理相关性流向追踪与主线程提交采样验证；不声称GPU加速或真机性能。
