# signature-experience Specification

## Purpose

为主题提供统一的品牌轮廓、安歇草地与窄溪、可复制代码、分享元数据与原生页面转场，使阅读体验完整，同时在减少动效、无脚本、权限拒绝或浏览器不支持时保持内容和导航可用。

## Requirements

### Requirement: 用户轮廓品牌

主题 MUST 以用户图片主体轮廓作为基本 logo，透明底单色，保持负形与比例；首页/内页/404/favicon/默认分享图 MUST 使用同一轮廓，并适配昼夜模式。

#### Scenario: 昼夜品牌一致
- **WHEN** 在 1440 与 390 视口切换昼夜
- **THEN** 品牌清晰、比例稳定、无白色矩形背景且不遮挡正文

### Requirement: 安歇草地与窄溪

场景 MUST 以纸墨单色呈现低伏草地与一条前景约26.5vw宽的溪流，溪水以多方向细波交叉叠加的连续灰阶明暗呈现波光，避免单组平行条带主导；地形、岸线与草根固定，中近景草簇和水面明暗 MUST 由同一空间风场缓慢连续驱动，相邻草簇有共同风向与传播节奏，根部固定；溪岸 MUST 以浅水渐变及疏密贴岸草簇自然衔接，避免整齐切线；1440/390两档昼夜 MUST 保持构图可辨，正常状态六至八秒内可察觉局部变化，中央主句和阅读区保持稳定。每秒绘制 MUST 不超过24个逻辑帧；后台、离页、减少动效或saveData MUST停止循环；减少动效/saveData MUST呈现确定性静态首帧。features.scene=false MUST不输出Canvas或场景脚本；无JS或Canvas不可用 MUST保持正文与导航可用。旧features.sea开关移除。

#### Scenario: 动画与恢复
- **WHEN** 正常页面经过时间后进入后台再恢复
- **THEN** 仅局部草梢与水纹变化，地形岸线不移动，后台无持续绘制，恢复平滑继续

#### Scenario: 静态降级
- **WHEN** reduce motion、saveData、关闭场景或无JS
- **THEN** 无持续动画，正文导航正常；reduce/saveData保留静态景观，关闭或无JS保留纸光颗粒底面

#### Scenario: 昼夜与小屏
- **WHEN** 在1440/390切换昼夜
- **THEN** 相同地形与草簇保持稳定，窄溪在两档可辨，切换900ms内完成且无闪白

### Requirement: 代码阅读与复制

Markdown fenced code MUST 显示透明细线单色代码块与语言标签，长行只在代码内横滚。增强后 MUST 提供本地化、键盘可达的复制操作，复制原始代码，不含行号/标签/按钮且保留换行；失败 MUST 明确提示并支持手动选取；无 JS MUST 仍可读。

#### Scenario: 完整原文复制
- **WHEN** 用户通过键盘或指针复制含缩进、HTML 字符和尾换行的代码
- **THEN** 剪贴板与原始代码完全一致，并宣布复制成功

#### Scenario: 拒绝与降级
- **WHEN** 剪贴板拒绝、未知语言、空代码或禁用 JS
- **THEN** 页面无错误，代码完整；拒绝时提供手动复制提示，无 JS 不出现无效复制控件

### Requirement: 社交分享元数据

每个 HTML 页面 MUST 提供 OG 与 Twitter large-card 的标题、摘要、绝对 URL、图片、alt；默认图片 MUST 为1200×630品牌与当前页面标题构成的逐页图片，中文、英文及长标题 MUST 保持在安全区；构建专用OFL字体 MUST NOT 自动发布给浏览器；页面 MUST 能以 bundle 或 assets 本地图片覆盖；文章 MUST 带类型与发布时间；构建 MUST 离线且无需额外工具。

#### Scenario: 默认与覆盖
- **WHEN** 渲染中文或英文文章以及具有图片覆盖的 fixture
- **THEN** 元数据对应当前页面与语言，图片 URL 可请求、尺寸正确且覆盖优先

### Requirement: 原生页面转场

features.transitions=true MUST 为支持的同源跨文档导航提供正文纵向退出/入场，时长取 220/520ms 令牌；框架与背景 MUST 保持静止。reduce motion MUST 即时导航；关闭、不支持、无 JS MUST 保持原生链接、锚点、历史与滚动恢复。

#### Scenario: 原生导航保持
- **WHEN** 用户导航、前进后退或访问片段
- **THEN** URL、正文、焦点/片段与原生滚动行为正确，转场结束无残留覆盖层

#### Scenario: 减少与关闭
- **WHEN** 启用 reduce 或关闭 transitions
- **THEN** 不出现转场位移，导航完整可用

#### Scenario: 草水共享风与自然岸边
- **WHEN** 在1440/390昼夜正常浏览场景
- **THEN** 风经过时邻近草簇顺势弯曲与回弹，水波方向/强度同时响应；固定岸边呈连续浅水与草簇遮掩过渡，地形和草根不漂移

### Requirement: 首页首屏聚焦

首页 MUST 以居中主句与低伏草地/窄溪作为首屏焦点，近期文章与附加正文 MUST 在下一可滚动区域完整可达；MUST 保持原生滚动及无JS阅读。

#### Scenario: 首屏与下方内容
- **WHEN** 在1440或390视口访问首页并向下滚动
- **THEN** 首屏聚焦主句，随后可访问全部近期文章与正文，固定框架无叠印或横向溢出

### Requirement: 本地场景调参
开发预览工具 SHALL 在独立本地页面实时调整溪流几何、浅岸、草密度/高度/摆幅及共同风力/风向/周期，提供桌面/手机及昼夜预览，不出现在正常主题页面或 Hugo 发布产物。工具 SHALL 支持带单位的参数 JSON 复制、下载、校验导入及恢复默认。

#### Scenario: 微调与参数回传
- **WHEN** 用户调整滑块、导出参数并重新导入
- **THEN** 实际主题画布立即反映参数，JSON 往返一致
- **AND** 系统减少动态效果偏好仍优先，关闭调参页不修改主题默认文件
