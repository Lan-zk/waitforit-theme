# 溪流材质、清晰草叶与固定星点

2026-10-21。对照 [Earendil 实站](https://earendil.com/) 的昼夜画面，参考截图及来源在 `docs/design/reference/2026-10-21-landscape/`。未复制其shader、样式或素材。

保留用户回传的16项默认参数。水面改为五尺度交叉波，使用随河道弯曲的透视坐标、朝近岸的缓慢水流、坡面反射与局部波光；竖屏保留足够横向细节。草改为长短、宽窄、倾斜各异的尖叶，固定根部、成片受风。草叶与星点按CSS像素绘制（宽度最多1440），水面独立采样到等效视口宽度最多900，避免把低分辨率草簇放大。星点固定、大小亮度不同，夜间更明显；首页顶部纸光变薄，主句附近仍有保护。

`before/`、`after/` 为相同参数的1440×900和390×844昼夜静态首帧对照。`meadow-day.mp4`、`meadow-night.mp4` 为约9秒实际浏览器录像，按采集墙钟时间编码；录制采样约7fps，不代表场景绘制帧率。`visibility/` 保存实际运动和reduce对照，`signature/` 包含阅读区及主题切换截图。

验证保留此前的画面强度上限，没有为新材质放宽测试：草地平均差≤10/255、单像素差≤64/255；水面平均差≤12/255、单像素差≤64/255；主句变化比例<0.1%。第一次检查发现白天草叶重叠处过深、水面变化稍强，已降低绘制增益。草叶路径观测改为每片尖叶的首条曲线，直接检查固定根部和邻近运动一致性。
