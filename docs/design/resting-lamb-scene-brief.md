## 1. 设计意图与范围

Logo 的含义来自用户提供的描述：低伏、紧凑、平衡、连续柔和曲线，暗示羔羊休息时的身体与头部；传达安静的敬虔、谦卑、信靠与基督信仰中的温柔。背景应成为这个标志可以安歇的环境，不承担讲述完整宗教故事的任务。

将体验从“纸面悬在开阔海上”转为“信笺安放在静谧草地旁”。保留 Earendil 带来的排版、留白、纸墨质感与克制交互；场景的构图和运动建立自己的语义。草地提供稳定、承托的主体，窄溪提供轻微、连续的生命感。

范围限于背景场景、相关令牌、配置命名、必要的 fixture 与契约/验收同步。保留现有 `emblem.svg` 的轮廓、负形和比例，保留字体、框架、正文宽度、菜单、星形指针、代码复制、OG 机制和原生导航。不要把 logo 变成背景里的具象羊，也不要新增牧羊人、十字架、日出光束或场景插画。主题显示名不在本任务内。

## 3. 目标画面

### 构图：低伏、承托、有留白

- 保持中央主句的位置和首屏后的文章区域。草地从约 60% 视口高度开始，主要占下方约 40%；顶部和主句周围仍以纸光留白为主。
- 用两到三片宽而浅的地形明暗形成连续地面。远缘轻微弯曲，局部高差建议先控制在 2–4vh；这是静态地形高差，不是动画振幅。远缘柔和融入纸色，不画一根横贯全屏的锐利边线。
- 草地呈现细短、有方向性的柔曲纹理：远处合为明暗，近处少量草梢可辨。组织成疏密不同的低矮簇群，整体保持留白，避免等距条纹、网格和整齐排列。
- 一条浅而窄的溪流从偏右远景缓缓弯向右下前景。岸线固定、弯曲平缓，局部可被草地遮挡；前景宽度建议 6–10vw，水面面积控制在可见地面的小部分。不要让溪流横贯全宽，也不要画成高反差白色道路。
- 溪水的识别依赖“固定岸线内的轻微流向纹理”，草地的识别依赖“固定地形上的短曲纹理”。静帧就应能区分两种材质，不能只靠动画解释。
- 390px 下重新安排溪流中心线，使画面仍有草地、窄溪和留白；不能只裁切桌面右侧，造成溪流消失或占满底部。页脚周围降低纹理对比，保证控件可读。

这些数字用于第一版构图，需在 1440×900、390×844 的昼夜截图上调校。视觉完成标准是“先看到信笺与标志，再感到安静的地面”，不是满足占比就算完成。

### 色彩：以纸墨表现青草地

沿用现有纸色与墨色，通过透明度、密度和纹理表达青草地。本轮不增加绿色或蓝色：`DESIGN.md` 的无强调色约束是当前整体风格的重要组成。青草地是场景语义，不必依赖绿色才能成立。

日间是温暖纸底上的轻墨地面；夜间使用现有夜纸/夜墨角色，整体压低纹理对比。溪流只略微亮于相邻地面，不发光，不使用纯白闪点。昼夜保持同一地形和草簇分布，切换的是光感，不是重生成另一幅景观。

### 动效：地面安定，细部轻动

| 部分 | 运动约束 | 首轮建议值（需视觉复核） |
| --- | --- | --- |
| 地形、远缘、岸线、草根 | 保持固定 | 位移 0 |
| 近景部分草梢 | 围绕固定根部小幅弯曲；相邻簇有相关性，各簇相位略有差别 | 横向摆幅约 1–3 CSS px；周期 10–16s |
| 溪水 | 仅在固定水道内部沿切线缓慢漂移；弱明暗、无浪峰 | 漂移速度约 1–3 CSS px/s；以独立令牌定义 |
| 远景 | 静态或显著弱于近景 | 不放大细节、不闪烁 |
| 纸光、颗粒、Logo、框架 | 保留既有行为 | 颗粒静态；昼夜交叉淡化仍为 900ms |

周期和速度是不同量，按各自单位读取；`24s` 也不代表现有多频波形恰好每 24 秒无缝重播。新实现避免周期边界跳变，采用连续相位或平滑循环纹理。

连续观察 6–8 秒，应能察觉局部草梢与水纹变化；阅读正文时不应感觉整幅地面起伏、涌向镜头或周期性明灭。仅靠把旧波浪振幅降低不能满足要求。无需鼠标追随、滚动视差、自动运镜或额外入场动画。

## 4. 实现路线与代码边界

继续使用原生 Canvas 2D，保留现有 IIFE、双昼夜画布和单一动画循环。不要为这一场景引入 WebGL、动画库、远程素材或场景插件系统（AST-16）。

建议将 `paint()` 的波面计算替换为以下顺序，函数划分以代码清晰为准：

1. 在初始化/尺寸改变时生成确定性的地形轮廓、草簇位置、溪流中心线与宽度。固定种子或确定性公式只在构建几何时使用，不能每帧随机生成草纹。
2. 绘制纸底、固定地形低频明暗和静态草地纹理。优先缓存静态层，避免把每根草都放进全屏逐像素循环。
3. 在水道遮罩内绘制缓慢流动的弱纹理。岸线与水道宽度不随时间变化，纹理不得越过岸线。
4. 绘制有限数量的近景活动草簇；草根固定，只有草梢弯曲。根据视口限制数量，小屏主动减少细节。
5. 同一套几何与时间相位供昼夜着色。静态层缓存只因尺寸/必要样式变化重建，不因切换昼夜随机化。

保留 `prepare()` 的有界分辨率思想。首轮维持 640 内部像素宽度上限；草梢必须有足够采样宽度，出现闪烁时先简化细节，而不是直接提升全屏 DPR 或更换渲染器。没有必要保留已无用途的旧波场数组、坡度公式和海浪常量。

继续保持最多 24 个逻辑帧/秒。暂停、恢复、resize 防抖和步长封顶复用现有机制。reduce/saveData 用确定性的静态首帧；hidden/pagehide 停止循环，回来平滑继续。不能检测到的 OS 省电状态不作支持承诺。

无 JS、Canvas 上下文不可用或脚本加载失败时，现有纸光/颗粒底面和正文导航可用即可；这几种情况不承诺显示草地。关闭场景时不得输出 Canvas 或场景脚本。场景继续 `aria-hidden`、`pointer-events: none`，不增加焦点目标。

### 令牌与配置

- 推荐把唯一布尔开关改为 `params.waitforit.features.scene`，默认 `true`；同步主题/fixture 配置及两个 partial（CFG-05/07/08、TPL-03）。直接移除 `features.sea`，不保留旧键别名，不增加 sea/meadow/stream 多模式。此项属于建议的契约变更，执行时在新决策中明确记录。
- 将海面专属令牌替换为实际需要的场景令牌：例如 `--wf-scene-ink`、`--wf-scene-opacity-far/near`、`--wf-grass-sway`、`--wf-motion-grass-cycle`、`--wf-stream-speed`。最终名称和数值只定义一次，不保留失效的 `--wf-sea-*` 与 `--wf-motion-sea-cycle`。
- `--wf-horizon` 可继续表示地面远缘基准；首次保持 60vh。首页 veil 48–68vh 与阅读页径向保护先保留，只有截图证据证明必要时才改相关令牌。
- reduce 下运动时长及水纹速度归零，渲染器同时停止 RAF；静态地形参数保持不变。不要只让周期归零却继续绘制。
- 视觉参数写入 DESIGN 对应契约与 sidecar，再落到 `tokens.css`；几何算法内的采样数/种子不必变成站点配置。脚本沿用现有资源指纹与 SRI 发布链（AST-01/02/04）。

## 6. 执行顺序与完成标准

### 第一步：契约与 fixture

完成新决策、DESIGN/sidecar 和适用的 OpenSpec 变更说明。先写验收句：“地形静止、局部轻动、正文安定、昼夜一致、降级可读”。

复用首页、`signature-check` 双语页、长文章和 404。首页当前主句含 tide，页脚描述含 fictional coast；只调整这些直接参与场景审核的虚构文案，避免海洋文案干扰判断。可以使用“Letters find us in quiet places.” / “信，在安静处抵达。”作为 fixture 主句，不当作最终品牌文案，也不批量改写无关文章。

完成条件：场景范围、开关、目标参数与验收要求已有明确落点；静态 fixture 覆盖首页与阅读页；没有真实站点内容进入仓库。

### 第二步：静态场景

先实现固定草地、窄溪和昼夜着色，固定时间相位。用真实页面的最终合成截图检查，而不是只看裸 Canvas。

完成条件：1440/390 两档昼夜都能辨认安静地面和窄溪；不再是整片波面；主句、页脚、阅读栏无纹理干扰；移动端溪流没有意外消失。静帧不成立时继续修构图，不能用动效掩盖。

### 第三步：局部运动与降级

加入草梢和水纹运动，保持单一 RAF。录制至少 8 秒昼夜画面，并测试暂停、恢复、reduce、saveData、resize 和开关关闭。

完成条件：正常状态有细微可辨变化，地形/岸线位置稳定；每种暂停状态无持续循环；偏好切回正常后恢复；无 JS 与失败路径正文可读；不出现重启跳动或闪白。

### 第四步：验收与交接

- **截图矩阵**：首页 1440×900、390×844 × day/night；中英文阅读页、滚动后的首页、菜单打开和 404 至少覆盖两档。附 reduce 静帧、无 JS 和场景关闭证据。
- **可见性**：将 `test/sea-visibility.mjs` 改为场景对应名称并更新引用；正常状态改用约 6 秒间隔，采样实际草梢/溪流区域及主句/正文保护区域，避开菜单和页脚文字。旧两秒 1.2% 下限不沿用。先用通过视觉复核的新画面校准阈值，再固定阈值；同时约束背景变化范围与阅读区稳定，不能把“任一像素变化”当作成功，也不能逐次放松阈值追求通过。
- **静态对照**：reduce 下相同采样区域在同样等待时间后无变化。对画面变化与 RAF 活跃分别检查，避免“画面静止但循环空转”漏检。
- **绘制预算**：保留 `test/signature.mjs` 的暂停/恢复和关闭断言。若改用路径或 `drawImage`，替换现有 `putImageData` 计数探针，用测试侧 instrumentation 按逻辑帧记录；一次双主题绘制只算一帧，不能把草叶 path 次数或缓存画布调用数当 FPS。
